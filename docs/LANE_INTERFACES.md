# Initial shared interfaces (root-owned; 17 November 2026)

Independent local-first Django 5.2 project. Python 3.12 local is supported; container target Python3.13. PostgreSQL17 on a new loopback-only port. Root supplies config/requirements/operations. No paid resources or legacy writes.

A owns User(AbstractUser): internal bigint id, public_id UUID, unique normalized email, is_verified, session_epoch. Add Preferences/Device with integer versions. All cross-app user FKs use settings.AUTH_USER_MODEL. A owns core.OperationReceipt plus atomic durable replay helpers. Receipt kinds cover every keyed personal/staff/license/device action, with actor/operation/payload hash, resulting version/status/response. A owns reader progress/annotations/completion plus billing transactions; root will coordinate shared contract fixes.

C owns library Work/Edition/Revision/Unit/Paragraph/Asset/Rights records with UUID public IDs. Edition has work FK, locale, live_revision; Revision has edition FK, title, state, version, explicit per-format access_policy default deny and download policy. Unit/Paragraph carry stable IDs/anchors and ordering. Rights grants are revision/format/action/territory/time bound. No free access is inferred from no offer. Use service authorize_revision(user, revision, format='reader', action='read', territory='IN') and a typed domain denial; A/B call this same authorizer. Expose selectors/serialization through library/services.py, not duplicate rules.

C's asset upload kinds include reader_source/timing_map/rights_document as private non-deliverables. Generic audio input maps to audio_chapter output. Keep clone keys revision-scoped with explicit measured copies; no new asset service. Local storage uses an ignored root .local/ directory, cryptographic short-lived grants and private/no-store delivery. Do not claim local delivery proves R2 or CDN behavior. C should message actual model/helper signatures promptly.

B owns web routes/templates and static assets. Preserve logo, approved fonts, rectangular complete-image frames and gold ornament; UI locale is independent of edition. Reader calls the reviewed first-slice APIs for progress/annotation/completion; use actual API data, not demo JS counters. Preferences/search fields must match amended contracts. Account/Reader/Vault/SDE/quiz flows need semantic controls and truthful disabled features. C supplies learning/library views or APIs; B owns only their template integration.

Existing canonical artifacts are ../docs/product/project-maison-2026-11-16/implementation/. Root copies amended versions into contracts/. Module URLconfs expose API paths without /api/v1 prefix (root mounts that prefix). Root config uses web.urls for HTML, then API urls from accounts/library/reader/billing/learning. Each lane adds its AppConfig and migrations. No other lane edits config/urls.py or shared settings.

First technical acceptance uses original bilingual local-only fixtures (no claim of a released commercial title), real PostgreSQL, session/CSRF, rights checks, bounded preview/grant, progress CAS/replay, one annotation, explicit completion and logout denial. Actual book import/rights remains a separate draft-gated step. Use existing manifest/source evidence for candidate selection; never upload to the current platform as part of this local build.
