# Tides: controlled visual rebuild

This is a new independently composed, deterministic renderer. It reuses the
existing tested point-Moon physics, the shared Earnalism brand/safe-area modules,
and the exact prior narration/transcript/word timing for a controlled visual
comparison. It does not synthesize speech, change the score, append END, upload or
publish. That retained source is the older professor direction; it is not relabelled
as B/Ryan or as a newly trained Earnalism model.

The new source-bound coast illustration fills the picture context. A shaded
ocean-only globe, linear actual-attraction arrows and separately labelled relative
arrows explain the mechanism. The reference frame changes before outward arrows
appear. The connected ocean envelope is an exaggerated 2-D teaching illustration,
not a fluid simulation, 3-D volume calculation or local tide forecast.

Both compositions retain readable actual captions and complete canonical logo
clearance inside the shared destination profile. Decorative scenery can extend
under interface reservations; essential ink, reading boxes, arrows and diagram
extents cannot. A continuous light upper sky gives the unmodified transparent
dark-lettered logo contrast without a rectangular logo backing.

The actual source plan supplies hash-bound `font` (with its face index), `logo`,
`coast`, and both `formats` with `narration`, `transcript` and actual `timing`.
Actual rendering uses those portable paths, not the local preview defaults.
Include this module, adjacent `tides/model.py` and shared `src` modules in the
trusted orchestrator software overlay.

```sh
python -B -m unittest video_studio.tides_rebuild.test_renderer -v
python -B -m video_studio.tides_rebuild.renderer preview --plan /path/render-plan.json --output /new/proof-directory
python -B -m video_studio.tides_rebuild.renderer silent-body /path/render-plan.json --output /new/body-directory
```

Inspect proofs before the full body render. Final assembly must preserve the exact
selected soundtrack and append the exact approved END once. These geometry and
source tests do not establish complete motion playback, listening acceptance,
native Instagram behavior or permission to publish.
